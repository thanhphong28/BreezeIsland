# BreezeIsland v1.2.0 — Samsung Galaxy Z Flip 5 (One UI 9) Edition

### 🇻🇳 Tính năng nổi bật (Tiếng Việt)
- **Tối ưu riêng cho Samsung Galaxy Z Flip 5 (One UI 9)**:
  - Khắc phục triệt để lỗi thanh trạng thái và chip nhạc `[▷ Bài hát]` của One UI 9 đè lên Dynamic Island.
  - Tự động ẩn icon thông báo thừa trên thanh trạng thái ngay trên điện thoại thông qua quyền **Sửa đổi cài đặt hệ thống** (không bắt buộc cần máy tính).
  - Tự động bung thẻ điều khiển nhạc nổi bật trên cùng khi bắt đầu phát bài hát mới và tự ẩn thông báo nổi bị trùng của hệ thống.
- **Tương thích 100% App Ngân hàng & VNeID**:
  - Hoàn toàn **không sử dụng Quyền trợ năng (Accessibility Service)** và **không cần Root**.
- **Hỗ trợ đầy đủ Tiếng Việt & Tiếng Anh**:
  - Chuyển đổi ngôn ngữ tức thì ngay tại màn hình chính hoặc trong **Cài đặt → Hệ thống → Ngôn ngữ**.
- **Cập nhật trực tiếp trong ứng dụng (OTA Check for Updates)**:
  - Chỉ cần cài APK 1 lần duy nhất; khi có bản cập nhật mới trên GitHub, vào **Cài đặt → Kiểm tra cập nhật** để tải và cài đặt trực tiếp.
