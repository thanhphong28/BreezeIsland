# BreezeIsland v1.5.0 — True Top-Most Dynamic Island Over Status Bar Header

### New Features & Fixes
- **True Top-Most Header Overlay (`Đè trực tiếp lên trên dải icon Header — Xuất hiện trên cùng`)**:
  - Kept the full original Dynamic Island size, centered camera position (`baseTop`), and right-side `Split` bubble without shrinking, flipping, or dropping the card below the header.
  - Added active `WindowManager.LayoutParams.FLAG_FULLSCREEN` + `WindowInsetsController.hide(WindowInsets.Type.statusBars())` in `OverlayWindow` when the island expands across the header (`Toast` banner, `Expanded` card, `Stack`) so SystemUI hides the underlying status bar header icons and renders the Dynamic Island strictly on top.
  - Updated `StatusBarCleanup` (`ACTIVE_ISLAND_SLOTS`, `SPLIT_RIGHT_SLOTS`, `SEAMLESS_SLOTS`) to automatically mask right-side One UI icons (`managed_profile` `🏢`, `knox_container`, `volume` `🔇`, `wifi` `🛜`, `bluetooth`, `vpn`, `data_saver`, `hotspot`, `zen`, `alarm_clock`) underneath the `Compact` and `Split` island so no header icons bleed through.
- **Lock Screen Dynamic Island (`Hiển thị ngay trên Màn hình khóa khi chưa mở khóa`)**:
  - Full Lock Screen support (`FLAG_SHOW_WHEN_LOCKED`) + Quick Reply over Lock Screen (`ReplyActivity`).
- **Single Unified APK**:
  - Distributed as a single universal signed APK: **`BreezeIsland.apk`**.
