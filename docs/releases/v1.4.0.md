# BreezeIsland v1.4.0 — Lock Screen Dynamic Island, Anti-Overlap Header Layout & True No-Root Control

### New Features & Fixes
- **Anti-Overlap Status Bar Geometry (`Khắc phục triệt để lỗi bị các icon trên thanh trạng thái đè lên Dynamic Island`)**:
  - **Safe Status Bar Corridor (`Compact` & `Pill Toasts`)**: Calibrated the compact Dynamic Island right boundary (`anchorX + 48dp`) so the pill stops cleanly before Samsung One UI 9's right-side system icons (`🏢` Work Profile, `🔇` Mute/Vibrate, `🛜` Wi-Fi 6, `📶` Signal, `🔋` Battery), shifting extra pill width into the open space to the left of the camera.
  - **Left-Side Split Satellite (`Split` Mode)**: Moved the secondary Split satellite bubble (e.g. Charging `⚡` while Music `ılılı` is playing) and its liquid metaball bridge to sprout on the **LEFT** side of the main pill (in the wide-open corridor after the clock `10:14`) instead of on the right where system icons sit.
  - **Below-Header Wide Card Drop (`Toast` Banner, `Expanded` Card & `Stack`)**: When expanding to a full-width notification banner or media card, the wide card body drops smoothly to `statusBandBottom` (directly underneath the status bar header icons) while keeping the compact camera stem anchored around the punch-hole camera, ensuring zero header icon overlap in every state without requiring `AccessibilityService` or Root.
- **Dynamic Island on Lock Screen (`Hiển thị ngay trên Màn hình khóa khi chưa mở khóa`)**:
  - Added `FLAG_SHOW_WHEN_LOCKED` to `OverlayWindow` and `FullscreenProbe` so Android's `WindowManagerService` renders BreezeIsland directly on top of the Lock Screen (`Keyguard`) as soon as the screen turns on.
  - Fixed `OverlayRuntime` Lock Screen detection so `FullscreenProbe` never mistakes the Lock Screen for a fullscreen game/video.
  - Enabled **Quick Reply (`ReplyActivity`)** directly over the Lock Screen (`showWhenLocked="true"`, `turnScreenOn="true"`).
- **True No-Root / No-ADB Status Bar & Notification Control**:
  - Automatically snoozes active `MediaStyle` status bar notifications via `NotificationListenerService` when `Seamless status bar` or `One UI Live Notification / Media chip` is enabled, removing One UI 9's `[▷ Song]` status bar chip while keeping `MediaSessionMonitor` music controls 100% active.
  - Real-time suppression of system status bar notifications matching the selected icon switches (`vpn`, `hotspot`, `data_saver`, `bluetooth`, `zen`, `volume`, `rotate`, `headset`, `nfc`, `alarm_clock`) plus Samsung One UI `Settings.System` status bar flags.
- **Single Unified APK**:
  - Distributed as a single universal signed APK: **`BreezeIsland.apk`**.
